# 💸 aldia

> Mantén tus cuentas y finanzas personales siempre al día.

**aldia** es una aplicación web full-stack creada para eliminar la libreta de apuntes al momento de prestar dinero y gestionar servicios o arriendos.

### ✨ Características Principales
* 💵 **Control de Préstamos y Abonos:** Registro de capital, tasas de interés simples, plazos y cálculo de saldo pendiente en tiempo real.
* 📅 **Matriz de Servicios y Arriendo:** Visualización de cobertura por períodos para registrar y proyectar pagos realizados por adelantado.
* 🤖 **Recordatorios por WhatsApp:** Notificaciones y cobros automáticos sin costo integrando Baileys y Vercel Cron.
